# 🏛️ Sistema de Gestión de Asistencias - Ada 95

Este proyecto es una aplicación desarrollada en **Ada 95** como parte de la cursada de **Algorítmica y Programación II** en la carrera de *Analista Programador Universitario / Licenciatura en Informática* de la **Universidad Nacional de la Patagonia San Juan Bosco (UNPSJB)**.

El objetivo principal es aplicar conceptos de algoritmia, manejo estricto de tipos, estructuras de datos estáticas/dinámicas y persistencia en archivos.

---

## 🛠️ Tecnologías y Conceptos Clave

* **Lenguaje:** Ada 95 (Compilador GNAT / GCC)
* **Estructuras de Datos:** Arreglos, registros (`record`) y tipos definidos por el usuario.
* **Persistencia:** Manejo de archivos de texto / binarios para almacenamiento de datos.
* **Algoritmia:** Implementación de algoritmos de búsqueda, ordenamiento y modularización.

---

### Requisitos
